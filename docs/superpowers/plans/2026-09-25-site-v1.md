# Site do Dimension Riders v1 — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Colocar no ar, em GitHub Pages, o site estático bilíngue (EN padrão, PT-BR) do Dimension Riders com quatro páginas: Início, A Dobra, Baixar e Privacidade.

**Architecture:** Astro 7 com i18n nativo por prefixo de rota. As páginas em `src/pages/en/` e `src/pages/pt/` são finas e chamam "views" em `src/views/` passando o idioma; todo texto visível vem de `src/i18n/*.json` ou de `src/content/*.md`. Sem JavaScript no navegador exceto o redirecionamento por idioma na raiz. Testes com Vitest: paridade de dicionários, links internos no HTML gerado, e a regra do "fold". Deploy por GitHub Actions a cada push na `main`.

**Tech Stack:** Node 24 (mínimo 22.12), npm, Astro ^7.3.5 (traz `sharp` como dependência opcional para otimizar imagens), Vitest ^5.0.2, GitHub Pages, GitHub Actions (`actions/checkout@v7`, `actions/setup-node@v7`, `actions/upload-pages-artifact@v5`, `actions/deploy-pages@v5`).

**Spec:** `docs/superpowers/specs/2026-09-25-site-v1-design.md`. História e glossário: `~/projetos/dimension-riders-story/STORY.md` (ler antes de escrever qualquer texto).

## Global Constraints

- Repositório: `~/projetos/dimension-riders-site`, publicado em `https://murilogtoloni.github.io/dimension-riders-site/`; `base: '/dimension-riders-site'`.
- Idiomas: `en` (padrão) e `pt`; rotas sempre prefixadas (`/en/...`, `/pt/...`); `html lang` é `en` e `pt-BR`.
- Rotas por idioma: `fold`↔`dobra`, `download`↔`baixar`, `privacy`↔`privacidade`, raiz do idioma é a Início.
- Nenhum texto visível dentro de `.astro`: tudo vem de `src/i18n/<locale>.json` ou `src/content/<nome>.<locale>.md`.
- Em inglês, "fold" nunca é verbo na interface (o Cavaleiro *seals*, nunca *folds*); "the Fold" e "into the fold" são permitidos. Texto narrativo (a abertura da história) é exceção.
- O título "Dimension Riders" não se traduz. Termos seguem o glossário do STORY.md (Fold/Dobra, Amber/Âmbar, Tear/Rasgo, Mark/Marca, Unfolded/Desdobrados, Tyrant/Tirano, Riders/Cavaleiros, Shard/Estilha).
- Nunca afirmar a origem da Dobra nem o significado da Marca (STORY.md, seção 11).
- Imagens em `src/images/` (otimizadas pelo `<Image>`); nada de imagem em `public/` além do favicon e do `og.png`.
- APK não fica no site: link fixo `https://github.com/murilogtoloni/dimension-riders/releases/latest/download/dimension-riders-release.apk`.
- Sem JavaScript no navegador além do redirecionamento da raiz. Sem analytics, formulário, ranking ou bestiário.
- Mensagens de commit em português, terminadas com `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

import { DEFAULT_LOCALE, LOCALES, flattenKeys } from '../src/i18n';

      expect(empty).toEqual([]);

`src/i18n/index.ts`:

```ts
import en from './en.json';
import pt from './pt.json';

export const LOCALES = ['en', 'pt'] as const;
export type Locale = (typeof LOCALES)[number];
export const DEFAULT_LOCALE: Locale = 'en';

/** Valor do atributo lang do <html> e dos hreflang. */
export const HTML_LANG: Record<Locale, string> = { en: 'en', pt: 'pt-BR' };

export const PAGES = ['home', 'fold', 'download', 'privacy'] as const;
export type Page = (typeof PAGES)[number];

/** Slug de cada página em cada idioma. '' é a raiz do idioma (Início). */
export const ROUTES: Record<Page, Record<Locale, string>> = {
  home: { en: '', pt: '' },
  fold: { en: 'fold', pt: 'dobra' },
  download: { en: 'download', pt: 'baixar' },
  privacy: { en: 'privacy', pt: 'privacidade' },
};

type Dictionary = Record<string, unknown>;
const DICTIONARIES: Record<Locale, Dictionary> = { en, pt };

function lookup(dict: Dictionary, key: string): unknown {
  return key.split('.').reduce<unknown>(
    (node, part) => (node && typeof node === 'object' ? (node as Dictionary)[part] : undefined),
    dict,
  );
}

/** Texto da chave "a.b.c" no idioma; substitui {nome} por vars.nome. Lança se faltar: texto faltando é bug de build. */
export function t(locale: Locale, key: string, vars: Record<string, string> = {}): string {
  const value = lookup(DICTIONARIES[locale], key);
  if (typeof value !== 'string') throw new Error(`i18n: chave "${key}" não existe em "${locale}"`);
  return value.replace(/\{(\w+)\}/g, (match, name: string) => vars[name] ?? match);
}

/** Caminho absoluto (com base) de uma página num idioma, sempre com barra no fim. */
export function localePath(locale: Locale, page: Page, base: string = import.meta.env.BASE_URL): string {
  const root = base.replace(/\/+$/, '');
  const slug = ROUTES[page][locale];
  return slug ? `${root}/${locale}/${slug}/` : `${root}/${locale}/`;
}

/** Chaves folha de um dicionário no formato "a.b.c". Usado pelos testes. */
export function flattenKeys(obj: Dictionary, prefix = ''): string[] {
  return Object.entries(obj).flatMap(([key, value]) =>
    value && typeof value === 'object'
      ? flattenKeys(value as Dictionary, `${prefix}${key}.`)
      : [`${prefix}${key}`],
  );
}
```

    <script is:inline define:vars={{ targets, fallback }}>
      var langs = navigator.languages || [navigator.language || ''];
      var hit = null;
      for (var i = 0; i < langs.length && !hit; i++) {
        var code = String(langs[i]).toLowerCase().split('-')[0];
        if (targets[code]) hit = targets[code];
      }
      location.replace(hit || fallback);
    </script>
  </head>
  <body>
    <a href={fallback}>Dimension Riders</a>
  </body>
</html>

import type { MarkdownInstance } from 'astro';
import type { Locale } from '../i18n';

export type DocName = 'fold' | 'privacy';

const docs = import.meta.glob<MarkdownInstance<Record<string, unknown>>>('./*.md', { eager: true });

/** O Markdown de uma página num idioma. Lança se o arquivo faltar: página sem tradução é bug de build. */
export function loadDoc(name: DocName, locale: Locale): MarkdownInstance<Record<string, unknown>> {
  const doc = docs[`./${name}.${locale}.md`];
  if (!doc) throw new Error(`content: falta src/content/${name}.${locale}.md`);
  return doc;
}

import { existsSync, readdirSync, readFileSync, statSync } from 'node:fs';
import { join } from 'node:path';
import { describe, expect, it } from 'vitest';
import { BASE, DIST } from './helpers';

function htmlFiles(dir: string): string[] {
  return readdirSync(dir).flatMap((name) => {
    const path = join(dir, name);
    if (statSync(path).isDirectory()) return htmlFiles(path);
    return path.endsWith('.html') ? [path] : [];
  });
}

/** O arquivo que o GitHub Pages serviria para um href interno. */
function targetFile(href: string): string {
  const path = href.replace(/[?#].*$/, '').slice(BASE.length);
  return path.endsWith('/') ? join(DIST, path, 'index.html') : join(DIST, path);
}

describe('links internos', () => {
  const files = existsSync(DIST) ? htmlFiles(DIST) : [];

  it('dist/ existe e tem as 9 páginas (rode npm run build antes)', () => {
    expect(files.length).toBe(9);
  });

  for (const file of files) {
    it(`${file.slice(DIST.length)}: todo link interno tem a base e aponta para uma página que existe`, () => {
      const html = readFileSync(file, 'utf8');
      const hrefs = [...html.matchAll(/<a\s[^>]*href="([^"]*)"/g)].map((m) => m[1]);
      const internal = hrefs.filter((h) => h.startsWith('/'));
      const withoutBase = internal.filter((h) => !h.startsWith(`${BASE}/`));
      const broken = internal.filter((h) => h.startsWith(`${BASE}/`) && !existsSync(targetFile(h)));
      expect({ withoutBase, broken }).toEqual({ withoutBase: [], broken: [] });
    });
  }
});
